# 一箭又一箭（Python Pygame小游戏）
复刻微信小游戏《一箭又一箭》核心玩法，课程作业项目。

## 游戏规则
1. 棋盘上有上下左右四个方向箭头
2. 点击箭头：
   - 前方无阻挡：箭头飞出棋盘，直接消除
   - 前方有阻挡：箭头向前移动，碰到阻挡后缓动返回原位置；**同一个箭头在一关内只会消耗1次失误次数**
3. 失误次数耗尽 → 本关失败，可以重开
4. 清除全部箭头通关，弹出页面：【返回主页】 / 【下一关】

## 运行方式
1. 安装依赖
```
bash
 pip install -r requirements.tx
```
2.启动游戏
```
bash
python main.py
```
3.开发环境
##
Python 3.8+
Pygame
